# StudentPay

StudentPay is a university payment management system developed using PHP, HTML, CSS and MySQL.

## Features

- Student registration and login
- Student dashboard
- Cashier dashboard
- Cafeteria dashboard
- Balance checking
- Logout system
- MySQL database integration

## Technologies Used

- HTML
- CSS
- PHP
- MySQL

## Project Structure

- `controllers/` - Handles application logic
- `models/` - Database and user-related operations
- `views/` - User interface pages
- `styles/` - CSS files
- `student_pay_db.sql` - Database file

## How to Run

1. Install XAMPP.
2. Put the project inside `htdocs`.
3. Start Apache and MySQL.
4. Import `student_pay_db.sql` into phpMyAdmin.
5. Open the project from the browser.
